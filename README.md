This is a proof-of-concept project that builds a repo plugin for Munki 7 that uses the MunkiWebAdmin 2 API to 'talk' to the repo.

The repo plugin must be installed in `/usr/local/munki/repoplugins/`, and requires Munki 7.0.0 or later.

You can find the installer pkg in https://github.com/munki/MWA2APIRepo/releases
